## 多行处理

sed 默认一次处理一条记录，记录之间用换行分隔。模式空间里通常只有一行，而且不包含行尾换行。多行处理的核心，就是用命令把下一条记录读进当前模式空间，或者把模式空间拆成多行来操作。

这一篇讲四组容易混淆的命令：`n`/`N`、`p`/`P`、`d`/`D`，以及 `-z` 和 `M` 这两个 GNU 扩展。

### n 与 N

`n` 和 `N` 都会读下一行，但方式完全不同。

`n` 先用下一行**替换**当前模式空间：

```shell
printf 'a\nb\nc\nd\n' | sed -n 'n;p'
```

输出：

```shell
b
d
```

第 1 轮读入 `a`，`n` 读入 `b` 并替换模式空间，`p` 打印 `b`；下一轮读入 `c`，`n` 读入 `d`，打印 `d`。`a` 和 `c` 没有输出，因为 `-n` 关闭了自动打印，而 `n` 本身不打印。

`N` 把下一行**追加**到当前模式空间，中间用一个换行分隔：

```shell
printf 'a\nb\nc\nd\n' | sed -n 'N;p'
```

输出：

```shell
a
b
c
d
```

`p` 打印的是包含两行的模式空间，所以看起来是四行。`N` 每轮消耗两条输入记录，第 3 轮没有下一行可用，GNU sed 会结束处理，因此最后一行 `d` 没有单独输出。

如果希望最后一行也被处理，用 `$!N` 保护：

```shell
printf 'a\nb\nc\nd\ne\n' | sed -n '$!N;p'
```

输出：

```shell
a
b
c
d
e
```

`$!N` 的意思是“不是最后一行时才执行 `N`”。最后一行跳过 `N`，直接执行 `p`。

`N` 在最后一行上的行为在不同 sed 实现中不完全一致。写需要跨平台的脚本时，用 `$!N` 明确表达意图，不要依赖边界行为。

### p 与 P

`p` 打印整个模式空间。模式空间里有两行时，`p` 输出两行。

`P` 只打印到第一个换行之前：

```shell
printf 'a\nb\nc\n' | sed -n 'N;P'
```

输出：

```shell
a
b
```

第一轮 `N` 得到 `a` 换行 `b`，`P` 只打印 `a`；第二轮读入 `c`，`N` 没有下一行，结束。`P` 后面通常跟 `D`，组成滑动窗口。

### d 与 D

`d` 删除整个模式空间，开始下一轮，不再执行后续命令。

`D` 只删除到第一个换行之前，然后**不读新行**，直接从脚本开头重新执行：

```shell
printf 'a\nb\nc\nd\n' | sed -n 'N;P;D'
```

输出：

```shell
a
b
c
```

用四条输入走一遍：

| 循环开始时的模式空间 | `N` 之后 | `P` 输出 | `D` 之后 |
| --- | --- | --- | --- |
| `a` | `a<br>b` | `a` | `b` |
| `b` | `b<br>c` | `b` | `c` |
| `c` | `c<br>d` | `c` | `d` |
| `d` | `N` 失败，退出 | 无 | 无 |

关键在 `D` 之后：模式空间剩下 `b`，但 sed 不会去读下一条输入，而是从脚本开头重新执行。下一轮 `N` 才读入 `c`，所以窗口一次只向前滑动一行。最后一行 `d` 没有配对的下一行，`N` 失败，整个处理结束，`d` 没有被打印。

如果希望最后一行也输出，同样用 `$!N`：

```shell
printf 'a\nb\nc\nd\n' | sed -n '$!N;P;D'
```

输出：

```shell
a
b
c
d
```

`D` 有一个边界：如果模式空间已经空了，`D` 的行为和 `d` 一样，开始下一轮，不会无限循环。但脚本里如果反复 `D` 又没有减少内容，仍可能造成逻辑上的死循环，写循环时要在小样本上验证。

### 合并成对的行

`N` 最简单的用途是把两行合成一行：

```shell
printf '1\n2\n3\n4\n5\n' | sed 'N;s/\n/ /'
```

输出：

```shell
1 2
3 4
5
```

前两轮各合并一对；最后一行没有下一行，`N` 失败，GNU sed 打印当前模式空间，所以 `5` 原样输出。这个行为在不同实现中可能不同，跨平台脚本写成 `$!N;s/\n/ /` 更稳。

### 合并整个文件

下面的经典写法把所有行合并成一行：

```shell
sed ':a;N;$!ba;s/\n/ /g' examples/data/poem.txt
```

输出：

```shell
roses are red violets are blue sed is a stream editor and so are you
```

逐段解释：

- `:a` 定义标签。
- `N` 把下一行追加到模式空间。
- `$!ba` 如果还没到最后一行，跳回 `:a` 继续追加。
- `s/\n/ /g` 把所有内嵌换行替换成空格。

这个脚本会把整个文件装进内存。文件很大时，内存占用与文件大小成正比。处理大文件时，考虑用 `tr '\n' ' '`、awk 或流式工具。

### 合并段落

段落之间用空行分隔。下面的脚本把每个段落合并成一行：

```shell
sed -n '/./{H;$!d};x;s/^\n//;s/\n/ /g;p' examples/data/paragraphs.txt
```

输出：

```shell
Sed reads input line by line. It keeps the current line in the pattern space.
Multiple lines can be joined with N. The hold space survives across cycles.
This is the last paragraph.
```

逐步解释：

- `/./` 匹配非空行。非空行执行 `H`，把内容追加到保持空间；`$!d` 删除当前模式空间，开始下一轮，因此中间行不会输出。
- 遇到空行时，`/./` 不匹配，跳过 `H` 和 `d`，执行 `x`，把保持空间里的整段内容换进模式空间。
- `s/^\n//` 去掉第一次 `H` 留下的前导换行。
- `s/\n/ /g` 把段落内部的换行换成空格。
- `p` 打印合并后的段落。

最后一段没有结尾空行，`$!d` 在最后一行不删除，所以会走到 `x` 并打印。这个脚本假设段落之间恰好有一个空行；多个连续空行可能产生空段落，需要额外的压缩步骤。

### 压缩连续空行

下面的脚本把多个连续空行压成一个：

```shell
printf 'a\n\n\n\nb\n\nc\n' | sed '/^$/{N;/^\n$/D}'
```

输出：

```shell
a

b

c
```

遇到空行时，`N` 读入下一行；如果下一行也是空行，模式空间就是两个换行，`/^\n$/` 匹配，`D` 删除第一个换行并重启脚本。重复这个过程，直到只剩一个空行。

这个写法比 `cat -s` 更可控，但可读性一般。日常处理空行时，`cat -s` 或 awk 往往更直观。

### GNU 的 -z 与 NUL 分隔

`-z` 是 **GNU** 扩展，把记录分隔符从换行改成 NUL 字节。它在处理 `find -print0`、`xargs -0` 这类 NUL 分隔数据时很有用：

```shell
printf 'a\0b\0c\0' | sed -z 's/^/X/'
```

输出中的每条 NUL 记录都会加上 `X` 前缀。

`-z` 也可以用来把整个普通文本文件当成一条记录读入：因为没有 NUL，整个文件就是一条记录。

```shell
sed -z 's/\n/ /g' examples/data/poem.txt
```

输出是一行，行尾有一个空格：

```shell
roses are red violets are blue sed is a stream editor and so are you 
```

注意末尾的空格：文件最后的换行也被替换成了空格。`-z` 的输出不一定以换行结尾，管道下游的程序要能处理这一点。

`-z` 不是 POSIX 标准，BSD sed 通常不支持。跨平台脚本不要依赖它。

### M flag 与内嵌换行

`s` 的 `M` flag（**GNU**）让 `^` 和 `$` 匹配模式空间内部换行前后的位置：

```shell
printf 'a\nb\n' | sed 'N;s/^/X/Mg'
```

输出：

```shell
Xa
Xb
```

不加 `M` 时，`^` 只匹配整个模式空间的开头：

```shell
printf 'a\nb\n' | sed 'N;s/^/X/g'
```

输出：

```shell
Xa
b
```

`M` 只影响锚点，不改变记录如何被读入。模式空间里没有换行时，`M` 和普通模式没有区别。

### 常见陷阱

- **`N` 在最后一行失败**：不同实现行为不同；用 `$!N` 明确保护。
- **`-n` 加 `N` 丢掉最后一行**：`sed -n 'N;p'` 不会打印没有配对的最后一行，改用 `$!N;p`。
- **`p` 打印整个多行模式空间**：想只打印第一行时用 `P`。
- **`d` 和 `D` 混用**：`d` 结束整轮，`D` 只删第一行并重启脚本；语义差别很大。
- **把整个文件读进内存**：`N` 循环和 `-z` slurp 都会让模式空间随文件增长。
- **以为 `\n` 能匹配普通行尾**：行尾换行不在模式空间里；先 `N` 或 `G`。
- **`-z` 输出没有换行**：下游工具可能把多行当成一行，管道设计要检查。
